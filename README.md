# HACKUDO.EXE — Android WebView

Projeto Android com o painel HACKUDO.EXE.

## Compilar pelo GitHub usando apenas o celular

1. Crie um repositório no GitHub.
2. Envie todo o conteúdo desta pasta para o repositório.
3. Abra a aba **Actions**.
4. Se aparecer a opção, selecione **Build HACKUDO.EXE APK**.
5. Toque em **Run workflow**.
6. Aguarde o processo terminar.
7. Abra a execução concluída e procure **Artifacts**.
8. Baixe `HACKUDO-EXE-debug-apk`.
9. Extraia o arquivo ZIP e instale o `app-debug.apk`.

O workflow instala o JDK, Android SDK e Gradle no servidor do GitHub, então não é necessário instalar o Android Studio no celular.
